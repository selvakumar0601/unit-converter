# 📏 Unit Converter

A simple and responsive **Unit Converter Web Application** built using **HTML, CSS, and JavaScript**. This application allows users to quickly convert values between different length and weight units.

## ✨ Features

- 📏 Length conversion
- ⚖️ Weight conversion
- 🔄 Live conversion
- 🔽 Easy unit selection
- 🔢 Decimal result formatting
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
- ⚡ Fast and lightweight
- 💻 No backend or database required

## 📐 Supported Units

### Length

- Meter
- Feet
- Kilometer
- Mile

### Weight

- Kilogram
- Pound
- Gram
- Ounce

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
